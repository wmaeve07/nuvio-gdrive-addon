Get Your Google Credentials

We need to authorize the addon to read your Google Drive. Follow these exact steps:

A. Create OAuth Client:
1. Go to Google Cloud Console.
2. Create a New Project.
3. Go to APIs & Services > Library, search for Google Drive API, and Enable it.
4. Go to APIs & Services > Credentials. Click Create Credentials > OAuth client ID.
5. Application type: Web application. Name: Nuvio GDrive.
6. Under Authorized redirect URIs, click "Add URI" and paste: https://developers.google.com/oauthplayground
7. Click Create. Copy your Client ID and Client Secret.
B. Add Yourself as a Test User (CRITICAL STEP):
1. Go to OAuth Consent Screen.
2. Fill in: App name = "Nuvio GDrive", User support email = your email, Developer email = your email.
3. Click Save and Continue (skip Scopes).
4. On the Test users page, click + ADD USERS.
5. Add your Gmail address (the one you'll use for Google Drive).
6. Click Save and Continue, then Back to Dashboard.
⚠️ If you skip this, you will get "Access Blocked" error!
C. Get Refresh Token:
1. Go to OAuth 2.0 Playground.
2. Click the ⚙️ gear icon (top right). Check "Use your own OAuth credentials". Paste your Client ID and Secret. Close settings.
3. On the left, expand Drive API v3 and check https://www.googleapis.com/auth/drive.readonly.
4. Click Authorize APIs, select your Google account, and Allow.
5. Click Exchange authorization code for tokens. Copy the Refresh token.

Deploy to Cloudflare Workers
🚀 Quick Deploy: Click the button below to open Cloudflare Workers in a new tab. Keep this page open while you deploy!
🚀 Open Cloudflare Workers
Follow these steps:
1. The Cloudflare page will open in a new tab.
2. Enter a worker name (e.g., nuvio-gdrive).
3. Click "Create" or "Deploy".
4. Once created, click "Edit Code" or "Quick Edit".
5. Delete all existing code in the editor.
6. Paste the code you copied from Step 2.
7. Click "Save and Deploy" (top right).
8. Click "Visit" or copy your Worker URL.
📺 Install in Nuvio/Stremio:
After deployment, your addon URL will be:
https://nuvio-gdrive.YOUR_SUBDOMAIN.workers.dev/manifest.json
Paste this URL in Nuvio's addon installer!
💡 Tip: Your worker URL is based on your Cloudflare account subdomain. You'll see it after deployment (e.g., nuvio-gdrive.yourname.workers.dev).
